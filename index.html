Kuasai Aplikasi Quick Gemini dalam 3 Langkah Mudah

Pelajari cara menghubungkan akun Google Anda, mengatur API key, memilih model kecerdasan buatan terbaik, hingga menyesuaikan tema tampilan sesuai kenyamanan Anda.

Mulai Membaca Panduan Coba Demo Interaktif
Langkah 1

Login dengan Akun Google

Untuk memastikan percakapan dan pengaturan Anda aman serta tersimpan secara permanen di cloud, Anda diwajibkan untuk masuk menggunakan akun Google resmi.

Simpan Riwayat Percakapan (History): Semua percakapan Anda dengan AI tersimpan rapi dan dapat diakses kapan saja dari perangkat manapun.

Keamanan Terjamin: Otentikasi menggunakan standar keamanan Google OAuth tanpa menyimpan password Anda di server kami.

Klik tombol "Sign in with Google" di pojok kanan atas aplikasi atau di halaman sambutan awal.
🔐

Otentikasi Aman

Sinkronisasi Cloud dengan Google Drive / Firebase

Langkah 2

Memasukkan API Key & Memilih Model AI

Aplikasi Quick Gemini membutuhkan API Key pribadi Anda untuk terhubung langsung ke mesin kecerdasan buatan Google secara resmi, cepat, dan tanpa batas.

1

Cara Mendapatkan API Key

  1. Buka situs resmi Google AI Studio:
    aistudio.google.com/api-keys
  2. Login dengan akun Google milik Anda.
  3. Klik tombol "Create API key".
  4. Salin (Copy) kode API Key unik yang diberikan.
  5. Buka Settings di Quick Gemini, tempel (Paste) kunci tersebut pada kolom Gemini API Key.
2

Pilihan Model AI

Pilih varian kecerdasan yang sesuai dengan kebutuhan tugas Anda:

Gemini 1.5 Flash Rekomendasi / Cepat

Sangat cepat, efisien, dan cocok untuk percakapan sehari-hari atau tugas sederhana.

Gemini 1.5 Pro Kompleks & Analitis

Ideal untuk analisa data mendalam, penulisan dokumen panjang, dan pemograman rumit.

Langkah 3

Memulai Chat Baru & Mode Gelap

Setelah konfigurasi selesai, Anda siap memulai percakapan baru serta menyesuaikan tampilan visual agar nyaman di mata.

Memulai Percakapan Baru (New Chat)

Klik tombol "+ New Chat" pada bilah navigasi samping (sidebar) untuk membuat topik percakapan yang bersih.

Mengaktifkan Dark Mode (Mode Gelap)

Buka menu Settings (Pengaturan) > pilih opsi Theme > aktifkan Dark Mode untuk mengurangi kelelahan mata saat pemakaian di malam hari.
